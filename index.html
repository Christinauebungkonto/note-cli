note-cli

Notizen direkt im Terminal: schnell gespeichert, schnell aufgelistet, und sie bleiben auf deinem Rechner.

Die Befehle

note add <text>

Speichert eine Notiz und gibt ihren Hash aus.

note list

Zeigt alle Notizen mit ihrem Hash.

note delete <hash>

Löscht die Notiz mit diesem Hash.

So nutzt du sie

$ ./note add Milch kaufen
653d4ad29a1c5d5045882b9755fa0da8152fb02dba5c37dfe157664e560eeda5
$ ./note add Zahnarzt Dienstag 10 Uhr
90d9ed2a8ed0623eb7e76bbdf381f03636177373efa21c18542a092596c9780d
$ ./note list
653d4ad29a1c5d5045882b9755fa0da8152fb02dba5c37dfe157664e560eeda5  Milch kaufen
90d9ed2a8ed0623eb7e76bbdf381f03636177373efa21c18542a092596c9780d  Zahnarzt Dienstag 10 Uhr
$ ./note delete 653d4ad29a1c5d5045882b9755fa0da8152fb02dba5c37dfe157664e560eeda5

So liegen deine Daten

.notes/
└── db/
    ├── 653d4ad29a1c…   # Milch kaufen
    └── 90d9ed2a8ed0…   # Zahnarzt Dienstag 10 Uhr

Jede Notiz ist eine einfache Textdatei, ohne Titel und ohne Endung. Der Dateiname ist der SHA-Hash ihres Inhalts: gleicher Text, gleicher Name, keine doppelten Notizen. Der Ordner .notes/ entsteht in deinem aktuellen Verzeichnis und bleibt lokal.

Loslegen

$ git clone https://github.com/Christinauebungkonto/note-cli.git
$ cd note-cli
$ chmod +x note

Läuft unter macOS und Linux. Braucht nur bash, shasum und awk.
